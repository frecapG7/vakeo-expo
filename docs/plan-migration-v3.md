# Plan d'action — Migration API v1 → v3

Plan de travail frontend, à mettre à jour au fil des sessions (cocher `[x]`, dater, noter les décisions dans « Journal »).
Source backend : `docs/front-end-v3-migration.md`. Cartographie d'impact : `docs/architecture-agent.md` (sections marquées `⚠ v3`).

## Ruptures à absorber

1. `x-user-id` (raw ObjectId) → `x-user-token` (secret token, par trip+user)
2. Trip IDs dans les URLs : raw ObjectId → encodedId (opaque, fourni par l'API, jamais construit côté front)
3. Base URL `/api/trips/...` → `/api/v3/trips/...`
4. Nouveaux flows : join (avec siège), leave, rotate-token
5. Codes d'erreur : 401 sur mutations sans token, 403 sur lectures privées
